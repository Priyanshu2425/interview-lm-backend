backend/src/interviewer · system design

A graph examines a Candidate on a Corpus.

Everything under src/interviewer/ exists to serve one act: a deterministic LangGraph skeleton loads one Topic at a time, lets a small agentic region probe an answer, and writes Evidence exactly once — while a metered client counts every provider cent on the way through.

the stack

Six layers, and one rule about which engine they run on

HTTP arrives through four middlewares and an identity join before a router sees it. Routers hold no rules — strip the decorators and nothing is left. Services own the verbs, repositories own the SQL, and adapters/ holds one file per system we do not control.

Two engines, on purpose. Routes are async (deps_async.py); the LangGraph session runs on the synchronous engine (wiring.py, repository/core/). A Session ending through POST /end therefore goes through SessionEnding rather than writing on both — one transaction, one order.
the hot path

What one Answer Turn touches

The Answer Turn is a request, not a socket (ADR-0011). It resumes a parked graph, runs until the graph parks again, and returns whatever it parked on.

the law

What a suffix promises

A suffix is worth writing only where it tells you something the folder has not already said. Each row carries the test that decides it.

_router.py in routes/binds HTTP to a module, holds no ruledelete the decorators — is there anything left?

No _constants.py

A constant lives on the thing whose rule reads it — GradingMode.weight, EndReason.parks. A shared constants file is where two copies of one rule start.

Don't borrow another domain's word

Ingest's own cost policy is notebooks/ingest_cost_service.py, not a second metering. Words are decided in CONTEXT.md and used everywhere or nowhere.

A package exports its interface

service/notebooks/ exports NotebookService and its errors; the store behind it is internal. The __init__.py export list is the statement Python will not enforce.

enforced, not asked for

Four chokepoints

1
Every model call goes through MeteredModelClient

Nothing else may construct a provider client, and a static check enforces it. A call arriving without a topic_visit_id is rejected rather than recorded unattributed — metering, Evidence, provenance and refunds all key on the same unit.

2
Every Candidate-scoped route goes through current_candidate

Gatehouse says which member presented the token; IdentityStore says which Candidate that is. A route that wanted to trust a body would have to ask for it in writing, where a reviewer sees it.

3
Every ending goes through SessionEnding

Three callers stop a Session — the graph's last node, POST /end, and the resumption path that finds a process that died before the grade landed. Whether a reason parks or grades is a value here, not a string test copied into each of them.

4
Every Corpus read goes through the Dossier Loader

The only module that knows how Corpus content is stored — which is what makes a second Adapter (markdown_folder.py) writable against the contract alone.

absent APIs

The numbers this system will not produce

Each of these would be easy and natural to compute, which is why each is enforced as a call that does not exist. When you add a convenience, check that you have not re-opened one.

·
Coverage and Mastery are two readings, never one figure.

No function returns a combined percentage and no screen renders one.

·
Untested is not zero.

Below the Evidence Floor a Topic reads Untested and shows no number — even when a mastery figure is passed in beside an untested band.

·
A Credit is one US cent of provider cost.

Off the Credits route every figure is an em dash: a zero would read as "it was free" rather than "this ledger does not apply to you".

·
Difficulty is not a property of the Corpus.

None is recorded and none is derived. No screen calls a question easy or hard.

·
A Session's cost is not knowable in advance.

It is metered per graded call and reported after each Topic.

·
Pictures alone are not examinable.

A Source that extracts no text stays a stub; a figure may support a question grounded in text and may not be what one is grounded in (ADR-0024).

·
A Candidate is compared inside a Topic, never ranked.

A leaderboard needs one figure per person, and the only figures available are Coverage and Mastery — so a rank is the fused percentage under another name.

·
No Answer Key enters the interviewing context.

In MCP Mode the host holds its context in front of the Candidate. Grading material is redeemed directly by the Judge against a Visit id, single-use, and never passes through the host.
