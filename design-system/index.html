Scaler Cortex Interviewer

Prototype screens

Eight screens, each one responsive file shown here at both sizes. Mobile is the examination and nothing else: every secondary reading collapses behind a sheet. Desktop adds the two rails and the overlays the phone can't carry.

Palette and type come from Scaler's own shipped stylesheet. Layout structure comes from the two supplied references, with their video-call content removed: this product is text-first, and there is no face in it anywhere. Content is real — Module names, Topic names, ids and one Assignment/Answer Key pair are taken from the scraped Corpus. Every score, balance and transcript is synthetic and labelled.

01

Start a Session

Scope and duration, both fixed before the Session begins. The Module list carries real Topic counts and real Answer Key counts, so a Candidate can see which scope produces strong evidence before choosing it. There is no difficulty picker — the Corpus records none and we derive none. The provider notice says plainly that the cost can't be quoted.

02

The Topic Visit

The screen the product exists for. On mobile it is purely question and answer. Header, exchange, composer, nothing else; cost, grading mode and the Topic list all live in one pull-up sheet. On desktop the same file gains a Session rail on the left and the numbered Visit list on the right, the one structure carried over from the reference. Three turns are shown resolving into a single score, which is the interface making the one-Visit-one-score rule visible rather than asserting it.

03

Topic scored

The score, the rationale, and immediately underneath: who graded it, on which provider, under which rubric version, and what it cost. Then the posterior before and after: flat and dashed for untested, still wide after one answer. Coverage and Mastery appear as two separate readings, and Mastery reads not yet reportable rather than inventing a percentage from a single data point. The Answer Key is released only here.

04

Session summary

The screen that refuses the single number hardest. Coverage reads 5 of 71; Mastery reads 2 look solid, 1 looks weak — and never the two multiplied together. Each Topic carries its own distribution, so width tells you how much to trust the reading. The largest section on the page is the 66 Topics never asked about, which is the fact a conventional summary screen has no way to express.

05

Credits & keys

A Credit defined on the same screen as the balance: one US cent of real provider cost. The ledger shows an ungraded Topic that still cost money and its refund as a separate line. Both failure messages are rendered side by side so the difference is inspectable — the credit one names Credits and offers a top-up; the BYOK one names DeepSeek and the reason, and contains no reference to Credits at all.

06

Code Visit Future

The desktop overlay you asked for, and the reason it matters: the DSA Track grades at the lowest weight in the system today, and an executed test is deterministic evidence. The editor opens over the exchange rather than replacing it. Its footer states the unsolved part honestly — running tests is not answering, so submission stays a separate act. On mobile the screen explains why there is no phone-sized editor instead of shipping a bad one.

07

Voice Visit Future

Designed around its one genuinely hard problem instead of hiding it behind a waveform: a pause is not an ending, and interrupting yourself moves the boundary backwards. So the boundary the system thinks it heard is drawn, labelled, and movable. Getting it wrong doesn't produce a slightly worse transcript — it produces a permanent score for half a thought.

08

Operator console

Pool headroom leads because it is the only figure that can strand a Candidate mid-Session, and it is shown against its alert threshold so pre-funding is scheduled rather than reactive. Beside it, the unpriced call rate — the metering bug that would otherwise hide as free. Provider cost varies 5.3× and the grading weights do not move with it; the page says so, and says why no normaliser exists yet.
